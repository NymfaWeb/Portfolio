# Web Developer Portfolio & CV

A modern, responsive, and visually engaging web portfolio built with **Next.js**, **React**, and **Tailwind CSS**. It showcases my professional experience, skills, and selected projects.

## 🌟 Features

- **Modern UI & Aesthetics**: Uses glassmorphism, dynamic gradients, and smooth scroll behaviors.
- **Framer Motion Animations**: Micro-interactions, smooth reveals, and layout transitions for a premium feel.
- **Bot-Protected Contact Section**: Email addresses are hidden from simple scrapers and revealed securely via user interaction.
- **Responsive Design**: fully optimized for desktop, tablet, and mobile viewing.
- **Type-Safe**: Built with TypeScript.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/NymfaWeb/Portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
